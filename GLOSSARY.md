# Workspace Tab History

Workspace tab history identifies recently used tabs. It is independent for each Herdr workspace and session.

## Language

<a id="current-tab"></a>
**Current tab**:
The active tab in a workspace.

<a id="last-tab"></a>
**Last tab**:
The most recently used surviving tab retained in workspace tab history other than the current tab.
_Avoid_: Previous workspace, adjacent tab

<a id="workspace-tab-history"></a>
**Workspace tab history**:
An ordered list of a workspace's recently used distinct surviving tabs, including its current tab. A newly tracked workspace has no last tab; closing the workspace removes its history.
