# Workspace Tab History

Tab history identifies the previously used tab within each Herdr workspace. Each workspace's history is independent of other workspaces and sessions.

## Language

**Current tab**:
The active tab in a workspace.

**Last tab**:
The distinct tab that was active immediately before the current tab in the same workspace.
_Avoid_: Previous workspace, adjacent tab

**Workspace tab history**:
A workspace's current tab and optional last tab. A newly tracked workspace has no last tab; closing the workspace removes its history.
